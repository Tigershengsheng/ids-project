# 01｜先用一个故事理解整个项目

想象一所大学希望在新生入学时安排支持。它不能等到学生离开以后才说“我早就知道”。因此，我们只考虑入学时可以获得的信息，看看能否提前识别后来被记录为Dropout的学生。

这里有两个不同的问题。第一，模型能找到多少条后来的退学记录？第二，即使总体表现还可以，它会不会更容易漏掉某些群体？

## 我们实际做的事情

1. 用一个葡萄牙高校的历史数据，明确“退学记录”是什么意思。
2. 只选入学年龄、入学成绩和专业，训练一个模型。
3. 模型给每名测试学生一个分数，再按0.31这条共同规则决定是否预警。
4. 把预警和实际记录对照，统计找到、漏掉、误报和正确不报的人数。
5. 分别检查Female和Male记录，比较不同分母下的错误比例。

## 最重要的一组结果

在889名测试学生中，有285名被记录为Dropout。我们的规则找到187名，漏掉98名；另有222名没有该退学记录的学生也被预警。

Female组实际退学记录中的漏报率为44.4%，Male组为24.1%。同一个规则产生了不同的错误分布。

**可以讲出的结论：** 入学信息有一定预测信号，但误报、漏报和群体差异都很明显，需要进一步验证和人工审阅。

**不能讲出的结论：** 我们已经证明这个系统能减少退学，或者已经证明某个人一定需要或不需要支持。数据没有告诉我们这些。

# 02｜先认清“数据、变量、模型、结果”

把数据表想成Excel：一行是一条学生记录，一列是这个记录的一个属性。年龄这一列放年龄，专业这一列放专业，Target这一列放后来记录的结局。

| 英文 | 在本项目中的意思 | 例子 |
|---|---|---|
| Observation / record | 一条被分析的记录 | 一行学生资料 |
| Variable / feature | 描述学生的一列信息 | 年龄、入学成绩、专业 |
| Outcome / target | 想预测的实际记录 | 是否被记为Dropout |
| Model | 从训练资料学习出的计算规则 | Logistic regression |
| Probability / score | 模型输出的0到1分数 | 教学示例：0.40 |
| Threshold | 把分数变成预警的分界线 | 本项目0.31 |
| Prediction / warning | 模型的判断 | 预警或不预警 |
| Evaluation | 用实际记录检查判断 | 比较TP、FP、FN、TN |

## 最容易混淆的是哪两个东西？

**实际结局Y**来自原始数据；**预警R**来自模型。因为两者来源不同，才可能出现错误。若你把实际Target直接当成模型输入，就等于把答案交给模型了。

模型分数、预警和实际结局也不是同一回事。0.40是一个分数；在0.31阈值下会被预警；这个学生最终仍可能没有退学记录。

**小检查：** 如果模型预警，但原始Target是Graduate，这就是一次“预警与记录不一致”。不要因为预警就把Target改成Dropout。

公开只说明我们能够获取这些记录，不说明它能代表所有大学、所有国家或现在的爱丁堡学生。招生制度、专业设置、费用和支持方式都可能不同。

我们拿到的是历史记录，不是现场试验。数据没有让我们随机给学生分配支持措施，所以无法从这里证明某种支持“造成”了退学减少。

# 04｜三种原始标签怎样变成研究问题？

原始Target有三个类别。我们没有把仍在读的学生偷偷当成毕业生，也没有在主分析里删除他们。

| 原始标签 | 人数 | 原意 | 主分析Y |
|---|---|---|---|
| Graduate | 2,209 | 在记录终点为毕业 | 0 |
| Enrolled | 794 | 在记录终点仍在读 | 0 |
| Dropout | 1,421 | 在记录终点被记为退学 | 1 |

Y=1表示“被记录为Dropout”。Y=0表示“在这个终点没有该退学记录”。这里的0不等于“已毕业”，更不等于“永远不会退学”。

## 为什么可以合成0和1？

因为我们的主问题是“能否识别这个观察终点的退学记录”，不是分别预测毕业、仍在读和退学三种结局。二分类是对研究问题的选择，原来的三个标签仍保留用于解释和敏感性检查。

这项选择有代价：Enrolled学生还没有最终毕业结局，把他们归在0里会使预测含义依赖这个观察终点。因此展示中必须说明终点，备用页还检查了排除Enrolled后结果怎样变化。

## 代码的意思

```r
dropout = as.integer(Target == "Dropout")
```

`==`先判断是否相等，得到TRUE或FALSE；`as.integer()`把TRUE变为1、FALSE变为0。这不是把原始Target重写成毕业，而是另外建立一个二分类结果列。

# 05｜“入学预警”到底预测什么时候？

**预测时点：入学时。观察终点：专业的正常学制结束时。** 原始论文说明多数专业为3年，护理为4年。它不是“下个月会不会退学”，也不是“第一学期会不会退学”。

原始定义还把换专业或转到其他高校记为Dropout。因此这里的退学记录，比“永远离开高等教育”更宽泛。

## 一个教学示例

一名学生入学，后来转到另一所大学继续读书。原始数据可能仍将这条记录归为Dropout。模型若把他识别出来，是识别到了这个行政定义，不能据此说他学习失败或一定需要干预。

## 为什么这会改变我们的结论？

标签定义决定模型在学习什么。它学习的是与记录相符的模式，不能自动理解学生离开的原因、个人意愿或真实支持需求。

数据没有每个学生的离开日期，也没有可以直接用于按时间切分的入学年份字段。虽然论文给出总体年份范围，我们仍不能假装已经做了“用早年训练、晚年测试”的验证。

## 你需要能讲出的三句话

1. 我们预测的是正常学制终点的行政退学记录。
2. 这个标签包含一些转学或换专业情况。
3. 识别记录不等于识别谁一定需要帮助，更不等于证明干预有效。

**对应展示第2页。** 讲清楚这一步，是后面所有模型结果成立的前提。

# 06｜为什么不能把所有列都放进模型？

如果研究“入学时预警”，模型只能使用当时已经能知道的信息。第一、第二学期成绩是在以后产生的，不能拿它们假装做入学预测。这叫预测时间上的data leakage，数据泄漏。

| 信息 | 主分析怎么处理 | 原因 |
|---|---|---|
| 入学年龄 | 使用 | 与入学时点匹配 |
| 入学成绩 | 使用 | 是入学已有信息，尺度0-200 |
| 专业Course | 使用 | 入学专业类别 |
| 记录性别Gender | 分组审计；额外模型才使用 | 用来检查群体错误，主模型不使用 |
| 日间/夜间就读 | 不加入主模型 | 训练数据中由专业完全决定，信息重复 |
| 第一、第二学期成绩 | 排除 | 入学时还没有发生 |
| 欠费、缴费状态、奖学金 | 保守排除 | 个体记录时间不明确 |
| 宏观经济指标 | 排除 | 简化主模型，且缺个人年份核对 |

## 一个直观类比

你想在开学前预测期末表现，却把期末成绩交给模型。结果可能很好，但开学前根本无法获得那一列，因此不能完成原来的任务。

排除某列不等于它没用。例如学期成绩可用于“第一学期结束后的预警”，但那是另一个预测时点，需要重新设计问题和验证。

**要记住的选择理由：** 我们优先保证信息可用时间清楚，而不是尽量把结果做得好看。

# 07｜数据检查和数字编码怎么理解？

当前R检查发现：4,424行，37列，没有NA单元格，没有完全相同的整行重复，年龄范围17-70岁。没有NA不代表所有信息都完整可靠。

## “未知”可能写成数字

例如父母学历中的34表示Unknown。这样的格子不是NA，但含义仍是未知。父母职业中的90/99也要按字典解释，不能直接视为普通职业或一律删掉。本模型没有选择这些变量，仍记录了这项限制。

## 为什么Course要变成factor？

专业编号是名称的编码，不是数量。例如代码更大不表示“专业更多”，也不表示专业之间相差几千个单位。如果把编号当连续数字，模型就会强加不合理的大小和距离关系。

```r
course = factor(as.character(Course))
```

`as.character()`把编码作为文字标签；`factor()`告诉R：这是不同类别。模型可以给不同专业不同的基准水平。

## 为什么记录性别只显示两组？

原始文件只有0和1，对应Female和Male。我们报告的是这两个记录类别，不是完整的性别身份分类，也不能声称已经评估所有学生群体的公平性。

**小检查：** “没有NA，所以数据没有任何偏差”对吗？不对。定义、编码、未记录的信息和来源代表性仍可能有问题。

# 08｜先补上看图需要的统计基础

**Mean平均数：** 所有数加起来再除以人数。**Median中位数：** 把数排序后的中间位置。很大的个别数容易拉动平均数，中位数通常较稳。

**SD标准差：** 表示个体数值的离散程度，和原变量同单位。**IQR四分位距：** Q3-Q1，是中间50%数值覆盖的宽度。这些都不是模型准确率。

## 箱线图Boxplot怎么读？

1. 箱子中间的线是中位数，不是平均数。
2. 箱子下边是Q1，上边是Q3，中间约50%的记录在箱体范围内。
3. 在本项目的ggplot默认规则中，须延伸到距箱体不超过1.5×IQR范围内最远的观测值。
4. 须外面的点是按此规则单独画出的观测，不是自动判定的错误数据。

## 两个经常被误读的地方

箱子通常不是置信区间，箱子窄也不代表模型更准确。默认等宽箱体本身也不能表示各组有多少人，所以我们在类别下面补上n。

两组箱体重叠，说明只看这个变量很难把每个人完全分开；即便中位数不同，也不能说组内每个人都符合这种趋势。

**一句练习：** “退学记录组的年龄较高，但与其他组有重叠，所以年龄有群体关联，不决定个人结局。”

# 10｜为什么分训练、验证、测试三份？

可以把它理解成“学习规则、选择用法、最后检查”三个不同工作。下面只是学习类比；实际分析按学生记录划分。

| 数据部分 | 人数 | 负责什么 | 不该负责什么 |
|---|---|---|---|
| Training训练集 | 2,652 | 估计模型里的参数；看初步分布 | 假装是全新表现 |
| Validation验证集 | 883 | 选择共同阈值 | 当作最后无偏的成绩单 |
| Test测试集 | 889 | 检查已经固定的模型和阈值 | 反复帮我们挑最好看的方案 |

为什么不在同一批资料上学习并打分？模型可能只是适应了已有资料中的偶然特征，这叫overfitting，过拟合。对训练资料的好表现不一定延续到新记录。

项目大约按60/20/20划分，并在原始结局和记录性别组合内随机分配，尽量保持组成相近。人数受各层取整影响，并不是精确60%、20%、20%。

## seed是做什么的？

`set.seed(20261105)`让相同环境中的随机划分可以重现。它不是给模型加分，也不能让某次划分自动更有代表性。

用结局进行分层划分本身不等于把测试答案交给模型；关键是最终模型拟合、特征选择和阈值选择没有使用测试表现。

这里没有按年份留出未来学生，因此测试结果仍是同一来源历史数据中的随机留出表现，不能称为未来部署验证。

# 11｜模型到底是一个什么东西？

我们的主模型是**Logistic regression，逻辑回归**。虽然名字有regression，它在这里用于预测一个二分类结果：Y=1或Y=0。

模型用训练资料学习年龄、成绩和专业与记录结局之间的模式，给新资料计算0到1之间的分数。这个分数用于排序风险和决定是否预警。

## 先不用公式理解

教学示例：两名学生得到0.40和0.20。模型把前者排得更高。0.40不表示“这个人40%已经退学”，也不表示模型对这次判断有40%信心；它是模型对所定义结局的概率估计，可靠程度要另行检查。

## 想看公式时再读这一段

先算一个加权分数z，再把z转成0到1之间的p：

`z = b0 + b_age × age10 + b_grade × admission10 + 专业对应的项`

`p = 1 / (1 + exp(-z))`

这里b是从训练集估计的参数。Course是类别，所以不同专业有不同项，而不是直接乘上原来的专业编号。

模型假设年龄与成绩对log-odds的作用是线性相加的，且没有在主模型中加入交互项。现实可能更复杂，模型也可能漏掉影响结局的重要信息。

**你不需要先会推导这个公式。** 先能解释“输入三类入学信息，输出一个概率估计；再用共同阈值变成预警”就抓住了主线。

# 12｜把核心建模代码逐行翻译

下面是实际分析中的核心语句，省略了周围保存文件和额外检查。代码不是另一种模型。

```r
primary_formula <- dropout ~ age10 + admission10 + course
primary <- glm(primary_formula,
               data = training, family = binomial())
validation$probability <- predict(
  primary, newdata = validation, type = "response")
```

| 代码 | 应该怎样理解 |
|---|---|
| `<-` | 把右边结果保存到左边的名字 |
| `dropout ~ ...` | 想用右边变量解释、预测左边结果 |
| 公式里的`+` | 加入另一个预测变量；不是拼接数据表 |
| `glm()` | 拟合广义线性模型的R函数 |
| `data = training` | 只使用训练资料拟合 |
| `family = binomial()` | 对二分类结果用二项分布模型，默认logit连接 |
| `predict()` | 用已经拟合的模型对指定资料算预测 |
| `type = "response"` | 输出概率尺度，不输出log-odds |
| `$probability` | 表中的probability这一列 |

`age10=age/10`，`admission10=admission_grade/10`只是换了单位。20岁写成2，130分写成13。模型参数会随尺度改变；这种重新表达本身没有增加新信息。

主模型没有Gender。额外模型才加入Gender作比较，但我们没有因为测试结果稍好就用它替换预先固定的主模型。

# 13｜为什么阈值是0.31，不是0.50？

分数和预警之间还差一条规则。本项目用：**分数大于或等于0.31，就预警。** 恰好0.31也属于预警。

教学示例：分数0.40在0.31规则下预警，在0.50规则下不预警。分数并没有变化，变化的是决定。

![验证集中不同阈值的表现](figures/validation-threshold.png)

图的横轴是阈值；纵轴是验证集上的比例。降低阈值通常会让更多人被预警，找到更多退学记录，也产生更多误报。

实际选择：在0.05到0.80、每次增加0.01的候选值中，先保留验证集Sensitivity至少70%的阈值，再选Specificity最高的；若同值则按阈值降序。选出0.31，验证集识别200/284，约70.4%。

**70%是我们的示例性分析目标，不是老师规定、大学政策或已证实的最佳标准。** 真实使用还要讨论支持名额、漏报和误报的代价。阈值只在验证集选择；测试集没有负责选择它。

<!-- PAGE: confusion -->
# 14｜先把四格表彻底看懂

这张confusion matrix把889名测试学生全部放进四格。列看实际记录，行看模型是否预警。四个字母可以暂时放一边，先看中文。

| | 实际Dropout：285人 | 无该退学记录：604人 | 行合计 |
|---|---|---|---|
| 预警 | TP=187：找到 | FP=222：误报 | 409 |
| 不预警 | FN=98：漏掉 | TN=382：正确不报 | 480 |
| 列合计 | 285 | 604 | 889 |

**Positive**在这里指“预警为退学”，不是“好消息”。**Negative**指“不预警”。True和False则说明这次判断与记录是否一致。

| 缩写 | 展开 | 在项目里发生了什么 |
|---|---|---|
| TP | True Positive | 预警，且实际有退学记录 |
| FP | False Positive | 预警，但没有该退学记录 |
| FN | False Negative | 不预警，但实际有退学记录 |
| TN | True Negative | 不预警，也没有该退学记录 |

核算：187+222+98+382=889；187+98=285；222+382=604；187+222=409。任何比例都应该能回到这些数。

“误报”只是相对于这个行政标签的预测错误。没有退学记录，不代表学生完全不需要帮助。

**先试一题：** 想问“实际退学记录里漏掉多少”，分母用285，不是889，也不是409。

<!-- PAGE: accuracy -->
# 15｜为什么不能只看Accuracy？

Accuracy，准确率，问的是全部测试学生中有多少次判断与记录一致：

`Accuracy = (TP + TN) / 全部人数 = (187 + 382) / 889 = 64.0%`

但不发任何预警，也能把所有604名没有退学记录的人判对。这个“Always no warning”基准的准确率为604/889=67.9%，比64.0%还高，却找不到任何退学记录。

| 规则 | 找到退学记录 | 漏掉退学记录 | Accuracy |
|---|---|---|---|
| 全部不预警 | 0/285 | 285/285 | 67.9% |
| 模型阈值0.50 | 80/285 | 205/285 | 71.9% |
| 模型阈值0.31 | 187/285 | 98/285 | 64.0% |

## 这是不是说明模型没用？

不能只凭这一项决定。若目的是找到可能需要进一步对话的学生，漏掉285人和漏掉98人的后果不同；但多预警也消耗资源。我们要同时比较两种错误，而不是挑一个最高指标。

当前数据中没有退学记录的人更多，这是类别不平衡的一种表现。多数类容易让“全部猜多数类”的准确率看起来不低。

**答辩可说：** “Accuracy alone would reward a rule that never warns anyone. We also report missed records and false warnings.”

这里没有证明0.31的实际社会效益一定高于0.50。若没有支持成本和干预效果数据，最终用途判断仍有限。

<!-- PAGE: sensitivity -->
# 16｜Sensitivity和FNR：先只看实际退学的人

先把没有退学记录的604人移出视野，只看285名实际被记为Dropout的测试学生。其中187人被找到，98人被漏掉。

| 问题 | 公式 | 结果 |
|---|---|---|
| 实际退学记录中找到多少？ | Sensitivity = TP/(TP+FN) | 187/285=65.6% |
| 实际退学记录中漏掉多少？ | FNR = FN/(TP+FN) | 98/285=34.4% |

Sensitivity也叫Recall或True Positive Rate，TPR。FNR是False Negative Rate，漏报率。两项分母相同，且Sensitivity+FNR=100%。

## 用100人理解

把65.6%理解成：在这批测试资料中，每100名有退学记录的学生，规则大约找到66名、漏掉34名。这是把真实比例缩放后的解释，不是另一次调查。

## 为什么不能说“系统保证识别70%”？

70%是验证集上的选择目标；验证实际70.4%，测试只有65.6%。不同资料上的表现会变化。测试的95%条件bootstrap区间约60.3%-71.0%，也没有保证未来人群达到70%。

**常见误读：** 把Sensitivity说成“预警的人中有65.6%真的退学”。这换了分母；预警者中的真实退学比例是PPV，见第18节。

**自问：** FN变大、TP不变时，漏报率会上升还是下降？会上升，因为真实退学记录中被漏掉的份额更大。

<!-- PAGE: specificity -->
# 17｜FPR和Specificity：只看没有退学记录的人

现在只看604名在终点没有Dropout记录的测试学生。其中222人仍被预警，382人没有被预警。

| 问题 | 公式 | 结果 |
|---|---|---|
| 无退学记录的人中误报多少？ | FPR = FP/(FP+TN) | 222/604=36.8% |
| 无退学记录的人中正确不报多少？ | Specificity = TN/(FP+TN) | 382/604=63.2% |

FPR是False Positive Rate，误报率；Specificity是特异度，也叫True Negative Rate，TNR。两项相加为100%。

## 两种“误报比例”不是同一个数

**222/604**问：没有退学记录的人中，多少被错误预警？这是FPR。

**222/409**问：所有预警中，多少不符合退学标签？这是1-PPV，约54.3%。它们分子相同，但分母不同，不能都简称为同一个误报率。

## 对学生支持意味着什么？

若每个预警都安排人工联系，FPR涉及会联系多少没有该标签的人。不过这些人也可能有支持需求；现有标签只记录结局，没有测量他们是否需要帮助。

阈值降到0.31后，测试误报率由阈值0.50时的45/604=7.5%升至36.8%。这与找到更多退学记录一起，构成需要解释的取舍。

**记忆方法：** 看到FPR，先说“实际没有退学记录的人里面”；看到FNR，先说“实际有退学记录的人里面”。

<!-- PAGE: predictive-values -->
# 18｜PPV、NPV和FOR：这次先看模型说了什么

前两页先按实际记录分组；这一页先按是否预警分组。这是为什么分母会改变。

| 先看哪群人 | 想知道什么 | 计算 |
|---|---|---|
| 409名被预警者 | 多少有退学记录？PPV | 187/409=45.7% |
| 480名未预警者 | 多少无退学记录？NPV | 382/480=79.6% |
| 480名未预警者 | 多少仍有退学记录？FOR | 98/480=20.4% |

PPV也叫Precision，阳性预测值。NPV是阴性预测值。FOR是False Omission Rate，等于1-NPV。NPV和FOR在未预警这群人内部相加为100%。

## FNR和FOR为什么不一样？

同样是98名漏掉的人：FNR=98/285，问所有实际退学记录中漏掉的份额；FOR=98/480，问所有没预警的人中仍有退学记录的份额。

## PPV和Sensitivity为什么也不一样？

同样是187名找到的人：PPV除以409名预警者；Sensitivity除以285名实际退学者。一个从模型决定出发，一个从实际结局出发。

**读比例前，先完整说出条件。** 例如“在所有被预警的学生中，45.7%有该退学记录”，比“模型45.7%准确”清楚得多。

最后，409/889=46.0%是Warning rate，预警覆盖比例。它既不是PPV，也不是Sensitivity；它反映需要处理多少预警。

<!-- PAGE: tradeoff -->
# 19｜第6页的核心发现：多找到，也多误报

比较的是**同一个模型**在两个阈值下的决定。概率排序不变，分类规则变了。

| 测试结果 | 阈值0.50 | 验证选定0.31 | 变化 |
|---|---|---|---|
| 找到退学记录TP | 80 | 187 | 多107人 |
| 漏掉FN | 205 | 98 | 少107人 |
| 无该记录却预警FP | 45 | 222 | 多177人 |
| 全部预警人数 | 125 | 409 | 多284人 |
| Sensitivity | 28.1% | 65.6% | 上升37.5个百分点 |
| PPV | 64.0% | 45.7% | 下降18.3个百分点 |

为什么找到更多，PPV反而下降？因为新增预警中既有真正的退学记录，也有很多没有该记录的人。预警数量增长得更快，所以预警里的命中比例下降。

## 怎样自然解释？

“降低阈值后，我们找到的退学记录从80增加到187，但误报也从45增加到222。所以不能只展示‘多找到107人’，还要告诉听众新增了177次误报。”

## 为什么要说“个百分点”？

从28.1%到65.6%相差37.5个百分点。它不是相对增加37.5%；相对变化要另除以原来的28.1%。讲义和展示谈比例差时使用percentage points，pp。

结论要包含资源问题：若联系409名学生，学校有没有能力跟进？当前分析没有提供这个答案。

<!-- PAGE: auc -->
# 20｜AUC和Brier：概率本身还要怎样检查？

阈值决定某一次预警，但模型还输出概率分数。AUC和Brier从不同角度检查分数，都是补充指标。

## AUC：能否把退学记录排得更高？

本项目主模型测试AUC约0.718。直观上，随机取一名有退学记录者和一名无该记录者，模型把前者排得更高的比例约71.8%；并列按一半计。0.5相当于没有排序区分，1表示这批资料完全排序正确。

**AUC=0.718不是“71.8%的学生判断正确”。** 它也不保证概率可靠，不代表学校有资源处理预警。阈值从0.50改到0.31，模型分数不变，所以AUC也不变。

## Brier score：概率离0或1结局有多远？

`Brier = mean((p - y)^2)`，越小表示平均概率平方误差越低。主模型约0.188，基准约0.218。

教学示例：实际y=1，预测p=0.8，误差为(0.8-1)^2=0.04；预测0.2，误差为0.64。Brier使用所有人的概率，不只看过没过阈值。

基准在分类时全部不预警，但它的概率列使用训练集退学比例，而不是全部设成0。因此其Brier不能直接用“全部概率0”的结果代替。

展示主要讲错误和支持含义；AUC、Brier和公式适合答辩备用。它们不是公平性证明，也不能单独决定是否部署。

<!-- PAGE: fairness-start -->
# 21｜公平性分析先固定哪些东西？

公平性不是“分成两组，哪组数字更高就说偏见”。先固定研究的正类、模型、阈值、群体和比例的分母。

| 符号或约定 | 本项目里的意思 |
|---|---|
| Y=1 | 实际记录为Dropout |
| Y=0 | 在终点无该退学记录，包含Graduate和Enrolled |
| R=1 | 模型分数至少0.31，被预警 |
| R=0 | 模型分数低于0.31，没有预警 |
| A | 数据中的记录性别类别，Female或Male |
| p | 连续概率分数，和二分类R不同 |

两组使用同一个已经固定的主模型和同一个阈值。下面所有主结果都来自同一批889名测试学生。

| 组别 | 总数 | TP | FP | FN | TN |
|---|---|---|---|---|---|
| Female | 575 | 80 | 138 | 64 | 293 |
| Male | 314 | 107 | 84 | 34 | 89 |
| 合计 | 889 | 187 | 222 | 98 | 382 |

三个标准各问一件事：**Independence先看全部人；Separation先看实际结局；Sufficiency先看模型决定。** 下一页开始逐个算。

当我们说“检查某标准”，指的是报告与该标准有关的实际比例和不确定性。有限样本里接近或不同，都不等于已经证明整个系统公平或歧视。

<!-- PAGE: independence -->
# 22｜Independence：谁更常收到预警？

Independence在这里问：不先区分实际是否退学，两个记录性别组获得预警的比例是否相同？也常称demographic parity，人口统计均等。

| 组别 | 预警人数TP+FP | 这一组全部人数 | 预警率 |
|---|---|---|---|
| Female | 80+138=218 | 575 | 218/575=37.9% |
| Male | 107+84=191 | 314 | 191/314=60.8% |

Female组预警人数218比Male组191还多，但Female组本来就大得多。比较覆盖比例时，应比较37.9%与60.8%，不能只比218和191。

## 符号看不懂时怎样翻译？

`P(R=1 | A=Female)`读成：“在Female组这个条件下，收到预警的比例。”竖线`|`就是“在……条件下”。

Independence要求模型决定R的分布不依赖群体A。对于二分类R，只需比较R=1的比例，因为R=0的比例是它的补数。

## 它和学生支持怎样关联？

若预警触发联系，覆盖率不同意味着两组被联系的份额不同。但单看这一行，不能知道谁更容易漏掉，也不能知道预警是否可靠。那分别是后面的Separation和Sufficiency。

**可以说：** 本测试集的预警率存在明显差别。**还不能说：** 只要把两组都调成同样预警率，所有公平问题就自动解决。

<!-- PAGE: separation -->
# 23｜Separation：相同实际结局，错误是否相近？

Separation先按Y分开，再比较两组的预警情况。实际退学者看漏报，实际未退学者看误报。二分类下，两层都要检查。

| 条件 | Female | Male | 在比较什么 |
|---|---|---|---|
| Y=1：实际Dropout | 144人 | 141人 | 真实退学记录的规模 |
| 其中漏掉FN | 64人 | 34人 | FNR=44.4%对24.1% |
| Y=0：无该记录 | 431人 | 173人 | 非退学记录的规模 |
| 其中误报FP | 138人 | 84人 | FPR=32.0%对48.6% |

**漏报比较：** 64/(80+64)=64/144=44.4%；34/(107+34)=34/141=24.1%。不是除以575或314。

**误报比较：** 138/(138+293)=138/431=32.0%；84/(84+89)=84/173=48.6%。

## 为什么这比看总人数更重要？

两组实际退学记录数量相近，Female却漏掉64名、Male漏掉34名。这对应标题里的“哪些学生容易被漏掉”。另一方面Male在无该记录者中误报比例更高。

主展示用FNR和FPR表达；比较TPR和FPR也是同一类Separation检查，因为TPR=1-FNR。只看TPR相同通常只检查equal opportunity的一层，不是完整Separation。

**准确结论：** 本测试集两组错误率不同，值得调查。原因可能涉及专业构成、未观测因素、标签与模型假设，不能从这一张表直接断定原因或歧视。

<!-- PAGE: sufficiency -->
# 24｜Sufficiency：收到同样判断，含义是否相近？

Sufficiency换一个观察方向：先按模型说的R分开，再问两组实际结局Y是否相近。既看预警者，也看没有预警者。

| 固定模型决定 | Female | Male |
|---|---|---|
| R=1：预警人数 | 218 | 191 |
| 预警者中实际Dropout，PPV | 80/218=36.7% | 107/191=56.0% |
| R=0：未预警人数 | 357 | 123 |
| 未预警者中实际Dropout，FOR | 64/357=17.9% | 34/123=27.6% |

第一层说明：同样收到预警，在这批资料里，Female的预警与Dropout标签匹配的比例较低。第二层说明：同样未收到预警，Male记录中仍为Dropout的比例较高。

## 为什么只检查PPV还不够？

PPV只涉及R=1。完整的二分类Sufficiency还涉及R=0；可以比较FOR，也可以比较NPV，因为两者互补。当前两层都保留。

## 它和Separation怎么区分？

FNR是`P(R=0 | Y=1,A)`，先锁定真实退学者。FOR是`P(Y=1 | R=0,A)`，先锁定没预警的人。两个条件顺序不同，不能互换。

这些差别说明“相同预警标签”的实际含义并不完全相同。它们是对有限测试记录的描述，不等于已经完成可推广到所有学生的公平性认证。

<!-- PAGE: fairness-cheatsheet -->
# 25｜五行指标放在一起，先读分母

下面就是第7页主图与第10页备用表的读法。每一行只比较同一个问题下的两组，不能把不同行百分比随意当成同一件事。

| 标准与问题 | Female | Male |
|---|---|---|
| Independence：全部人里多少被预警？ | 218/575=37.9% | 191/314=60.8% |
| Separation：无退学记录中多少误报？ | 138/431=32.0% | 84/173=48.6% |
| Separation：有退学记录中多少漏掉？ | 64/144=44.4% | 34/141=24.1% |
| Sufficiency：预警中多少有该记录？ | 80/218=36.7% | 107/191=56.0% |
| Sufficiency：没预警中多少有该记录？ | 64/357=17.9% | 34/123=27.6% |

## 两个看似矛盾、其实都正确的结论

Female实际退学记录中更容易被漏掉：FNR较高。Male未预警者中有退学记录的比例较高：FOR较高。

这没有矛盾。第一句从144名和141名实际退学者出发；第二句从357名和123名未预警者出发。它们不是在相同的人群里计算。

## 如何记住三种标准？

先问“筛选的第一步是什么”：全部人看预警，是Independence；先筛实际结局，是Separation；先筛模型决定，是Sufficiency。

讲结果时先说中文条件，再报分子、分母，最后报百分比。即使忘记缩写，也能让听众知道你比较了谁。

<!-- PAGE: fairness-tradeoffs -->
# 26｜为什么同一规则仍不保证公平？

主模型没有把Gender直接作为输入，但年龄、专业等变量可能与记录性别有关；现实机会和资料测量也可能有差异。因此“删掉性别”不能自动推出群体结果相同。

## 基础率Base rate先不同

测试Female组有144/575=25.0%的退学记录；Male组为141/314=44.9%。它们不是模型预测，而是实际记录的比例。

若某组实际正类更多，同样的误报率和识别率也可能产生更高PPV。具体关系可以写成：

`PPV = TPR × base / [TPR × base + FPR × (1-base)]`

不用背公式。只要理解：预警里有多少真实退学记录，还取决于原来有多少退学记录，不只由模型错误率决定。

## 三种标准不是三个必拿满分的按钮

在基础率不同、预测不完美等常见条件下，一些公平标准会冲突。不能要求所有指标同时相等而不讨论条件，也不能把“存在取舍”当成忽略明显差异的理由。

即使存在完美预测，Separation与二分类Sufficiency可以满足，Independence仍可能因基础率不同而不满足；因此不能随口背“任何情况三个永远不兼容”。

实际使用应该讨论支持机会、错误代价、标签含义和当事人的权利。本项目是诊断这些问题，不是已经替学校决定哪一种公平标准具有最高优先级。

# 27｜为什么要给比例加上不确定性区间？

我们看到的44.4%和24.1%来自有限测试记录。若拿到不同但相似的一批记录，计算结果会变。Bootstrap帮助估计这种变化有多大。

## 本项目的重复抽样，逐步想象

1. 保持已经训练好的模型、0.31阈值和每条记录的预测不变。
2. 在575名Female测试记录中，有放回抽575条；Male中也有放回抽314条。
3. “有放回”表示某条可能被抽多次，另一些这次没有被抽到。
4. 对抽出的记录重新数四格，计算各组FNR等指标和两组差值。
5. 重复5,000次，保留这些统计量中间95%的范围。

这5,000次不是新招募了5,000批真实学生，也不是获得更多独立信息。它用现有资料模拟统计量的变动。

## 条件区间Conditional interval是什么意思？

这里把模型和阈值固定住了，所以区间只反映在这套固定规则下重抽测试记录的变化。不包含重新训练或重新选阈值的变化，也没有处理入学届别之间的相关性。

增加bootstrap次数主要让模拟分位数更稳定，不会保证真实置信区间越来越窄。原始样本量、变异和方法都影响区间。

**95%也不是“95%的个体落在里面”。** 这个区间针对统计量，和年龄等个体值的分布范围不同。

# 28｜Bootstrap代码、区间和正负方向

下面保留真实代码的关键语句，省略循环外的数组准备。`ids`是该组记录的行号，不是学生新增编号。

```r
draws <- lapply(group_rows, function(ids)
  sample(ids, length(ids), replace = TRUE))
boot[b,,g] <- rates(confusion(
  test$dropout[ids], test$flag[ids]))
gap_boot <- boot[,,"Male"] - boot[,,"Female"]
quantile(x, c(.025, .975), na.rm = TRUE)
```

在实际循环中，先执行`ids <- draws[[g]]`，再计算该组四格与比例。`b`是第几次重抽；`g`是哪一组；`replace=TRUE`表示有放回。

代码保存的是**Male减Female**。FNR差值为24.1%-44.4%=-20.3个百分点，95%条件区间约-30.7到-9.5个百分点。

主讲从“Female多漏掉多少”出发，改成**Female减Male**，就是+20.3个百分点，区间+9.5到+30.7。反转区间必须同时取负并交换两端，不能只改一个负号。

## 怎样解释95%置信区间？

在抽样近似和方法适用的条件下，若反复取得类似资料并按同样方法构造区间，长期大约95%的这些区间会覆盖相应真实统计量。这里是bootstrap近似，不是无条件保证。

区间不跨0支持这次分析中有差值，但不能证明差值由性别歧视造成；跨0也不能证明两组相同。多个指标的区间还是逐项的，没有作同时推断校正。

# 30｜校准Calibration和Sufficiency不是一回事

模型给的是连续概率p，预警是把p按0.31切成0和1。**同样分数是否有相似结局**，与**同样预警标签是否有相似结局**是不同检查。

![按共同概率区间分组的描述性校准图](figures/probability-calibration.png)

图中每个点来自一个共同分数区间，例如0.2到0.4。横轴是区间内平均预测分数，纵轴是实际退学记录比例。接近对角线，表示这一段平均预测与实际较接近。

真实例子：Female在0.2-0.4这段有272人，平均分数29.6%，实际记录25.4%；Male有142人，平均29.5%，实际35.2%。这些是分箱描述，不是每个精确分数的证明。

点大小表示该格人数。当前图略去n<30的格子以免小组估计过于不稳定；这些格子仍在CSV里，图也没有给区间。因此不能凭图宣布分组校准成立。

总体校准可能掩盖分组差异；连续概率校准也不能直接证明按阈值切分后的二分类Sufficiency。答辩时先说清楚在检查概率p，还是标签R。

## 先看一段课堂风格的真实汇总

```r
training %>% group_by(gender) %>%
  summarise(n = n(), dropouts = sum(dropout),
            rate = mean(dropout), .groups = "drop")
```

每组n是人数；因为dropout只含0和1，`sum(dropout)`数出1有多少，`mean(dropout)`就是退学记录比例。`.groups="drop"`明确让汇总后的表解除分组，避免后续操作继续按组执行；单个分组汇总时通常也会自动解除，它不是提高统计质量的技巧。

# 37｜答辩练习：先回答问题，再补证据

## 为什么选这个题？

理解：我们关心入学时可能采取支持行动的场景，同时检查哪些记录更容易漏掉。不要虚构个人调查或校方合作。

English：“We wanted to study an early support setting and examine both overall errors and group differences.”

## 为什么不用学期成绩提高准确率？

理解：因为预测时点是入学；以后产生的信息不能支持这个时点的判断。若改成学期结束预警，要重新定义任务。

English：“Semester results were not available at our prediction time, so using them would change the question.”

## 为什么不用更复杂的模型？

理解：主模型少量变量、假设可解释，便于检查时间与错误。没有声称逻辑回归是最好的模型；复杂模型可留未来比较。

English：“We chose a small model we could explain and audit. We have not established that it is the best possible model.”

## 为什么准确率反而降低？

理解：降低阈值找到更多退学记录，但也增加误报；Accuracy把两种错误按人数合并，不体现所有支持代价。

English：“Lowering the threshold reduced missed records but increased false warnings, so accuracy alone does not capture the trade-off.”

## 差值区间不跨0，是不是证明歧视？

理解：不是。条件区间反映固定规则下的抽样变化，没有识别差异原因，也没有评估所有公平维度。

English：“It supports an observed difference under our analysis, but it does not identify discrimination as its cause.”
