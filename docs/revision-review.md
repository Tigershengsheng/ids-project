3. The eight main spoken blocks are synchronised between the HTML slide notes and the separate script. Detailed figure-review explanations remain preparation material.
4. Six repeated preparation paragraphs and a paragraph about the previous redesign were removed. The fuller explanations, methods, limitations and Q&A are retained.
5. Preparation questions give explicit counts for the baseline and all five fairness comparisons. The text distinguishes a measured gap from its unestablished cause.
6. The reading-PDF helper now updates total timing as well as per-slide timing when the script changes. All timing remains an estimate until a live rehearsal.
7. The entry-profile description now explicitly refers to the median shown by the boxplots. The group discussion distinguishes false-warning rates from absolute counts.
