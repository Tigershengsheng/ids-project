# Project files for the workshop

The two assessed documents are `presentation.html` and `report.html` at the repository root. Open the PowerPoint in `output/powerpoint/` for an editable classroom copy; its ten speaking slides carry the English notes. The eleventh slide lists sources.

The slide PDF and English rehearsal script are in `output/reading-pdfs/`. The team's local sharing ZIP also includes a separate Chinese rehearsal guide, the bilingual question bank, their sources and a bilingual change summary. Read the chart on slides 8 and 9 using the same horizontal scale on both pages.

From the complete team project, `python tools/package_delivery.py <output-folder> --include-rehearsal` packages the verified sources, data and exports together. From the public repository, omit the final option to package the English materials. The packager checks each archive entry against its source. Keep the data and analysis plan with the code when sharing the reproducible project.
